# Coastward screenshots

Drop real app screenshots here using these filenames, then replace the matching
`.shot-placeholder` div in `coastward/index.html` with an `<img>`.

| Filename                  | Placeholder (`data-screenshot`) |
| ------------------------- | ------------------------------- |
| `hero.png`                | Hero                            |
| `roster.png`              | Roster                          |
| `dates-destinations.png`  | Trip dates & destinations       |
| `expenses.png`            | Expenses                        |
| `meals-shopping.png`      | Meals & shopping list           |
| `activities.png`          | Activities                      |
| `photos.png`              | Photos                          |
| `emergency-info.png`      | Emergency info                  |

Portrait phone screenshots, ideally 1179 × 2556 (iPhone 15/16 native). Other
portrait sizes work but are cropped to the frame with `object-fit: cover`.
